Anime List Sync setup

This site issues the access tokens your daily sync workflow needs. Tokens are exchanged in your browser (or in a one-time GitHub Actions run) and are never stored here. Copy them into repository secrets afterwards.

Step 1 - Create the OAuth apps

AniList: open anilist.co/settings/developer, create a client, and set the redirect URL to exactly:

MyAnimeList: open myanimelist.net/apiconfig, create a client, and set the redirect URL to the same address above.

Step 2 - AniList token

You will be redirected to AniList and back. Your token is then shown here for you to copy.

Step 3 - MyAnimeList token

MyAnimeList blocks browser token exchanges, so after authorizing you will get a one-time code instead. You then run the Get MyAnimeList token workflow once and copy its output here - it takes under a minute.

Step 4 - Store the secrets

In your repository, open Settings > Secrets > Actions and add:

  1. ANILIST_TOKEN - the AniList token from step 2
  2. ANILIST_USERNAME - your AniList username
  3. MAL_TOKEN - the MyAnimeList token from step 3
  4. MAL_USERNAME - your MyAnimeList username

Optionally keep ANILIST_CLIENT_ID, ANILIST_CLIENT_SECRET, MAL_CLIENT_ID, MAL_CLIENT_SECRET and TOKEN_JSON for auto-refreshing tokens - see the README.

Anime List Sync - the sync workflow runs daily at 04:00 UTC and updates your README.
